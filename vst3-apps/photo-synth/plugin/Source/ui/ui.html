A Spectrum module is a character rather than an effect: it does not sit in the signal path but re-shapes how every voice is built. Arm any combination — where two reach for the same control the most recently armed wins, and each hands back what it took when released.

Automotion
Hold Shift and drag across any photo to lay down a line; hold Ctrl and drag to lay down a circle around the point you pressed. The cursor then walks that path on its own, and this panel opens on the pad you drew. Each pad keeps its own path and its own settings. Drawing a path makes no sound — the path does that once it is armed.

Speed multiplies the Motion slider in the title bar, so that one is still a master over all four. One shot walks the path once and stops where it ends; a new note, or a tap on the pad, fires it again. Sine eases into both ends of a line, Triangle holds one speed the whole way. Clockwise applies to circles, Triangle/Sine to lines; a recorded gesture uses Speed and Loop only.

A preset captures every control, the effect chain and FX matrix, the cursor positions, armed motions, and small copies of the photos. Presets are ordinary .json files in the folder you choose, so you can back them up, copy them between machines or sort them in Explorer. Subfolders become submenus in the list. To save into one, type Pads/Warm bells rather than just a name — the folder is made if it is not there yet. The folder is remembered for every project and every host until you choose another.
