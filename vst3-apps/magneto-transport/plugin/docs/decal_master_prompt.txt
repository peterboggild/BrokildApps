You are going to make a set of 37 image parts for a software audio plug-in called Magneto Transport, a tape echo drawn as a 1970s studio tape machine. A program assembles the parts at exact coordinates, so each part is a SEPARATE image. Never draw a whole panel and never combine parts.

HOW WE WORK
- Make exactly ONE image per reply, in the order of the list below, starting with part 1.
- Before each image, write one line: the part number, the file name, the size and the background (transparent, opaque or semi-transparent).
- After the image, stop and wait. I will answer "next", or "redo" with a reason.
- If I write "start at <file name>", continue the list from that part.
- Keep the same style, light and palette for every part, so the set looks like one machine.

RULES FOR EVERY IMAGE
- Use exactly the size given. Only three sizes are used: 1024 x 1024, 1536 x 1024 and 1024 x 1536.
- Transparent means a real transparent PNG background: fully transparent outside the object, fully opaque inside it. No white, grey or checkerboard background.
- Opaque parts fill the whole canvas edge to edge, with no border and no vignette.
- Fill the canvas as each part describes. A drawing sitting in a strip or a corner of a larger canvas is wrong.
- Tiling textures tile: the left edge continues into the right edge and the top into the bottom, with no single feature that would show as a repeat.
- Pairs (off/on, up/pressed): make the second from the first, at the same size and in the same position, so that switching between them changes only the light or the press.
- No text, logos or numbers, except where a part lists exact lettering.

STYLE (applies to every part)
A 1970s professional studio tape machine, photographed straight on, for a realistic software panel. Dark anodised steel and black crackle paint, with brushed aluminium reels, black rubber, and aged brass lettering and trim. It is a working machine that is well kept: fine scratches and a little dust, no rust, no dents, no grime. One soft light from the upper left at about 45 degrees, so highlights sit upper left and shadows fall lower right. Flat, orthographic, top-down view with no perspective, no tilt and no camera blur. No text, logos, numbers or labels unless this request lists exact lettering. No background scenery and no drop shadow outside the object unless asked.

Palette, use these and nothing brighter: near-black ink #0b0d0c, panel steel #1a1d1b, panel steel, raised #232724, edge / bevel #33382f, bevel highlight #4a5145, brass lettering #c9b27a, brass, dim #8a7a52, brass, low #5a5138, meter paper #d8cfb4, amber lamp #ffb340, red lamp #d2412c, green lamp #7fbf6a, tape oxide brown #4a3220, smoked glass #0a0b0a.
