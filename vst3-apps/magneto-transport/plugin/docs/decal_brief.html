Magneto Transport Decals

Image parts for a software tape-echo instrument. Each part is made on its own and the program assembles them, so please never paint a whole panel. A program places every part at exact coordinates, which an image generator cannot hit. What matters is that each part looks right on its own canvas, at its stated size, with real transparency where asked.

How to work

  1. Make the parts one at a time, one image per request. Press Copy full prompt on a card and paste it into ChatGPT: it already contains the style paragraph, the size, the background and the palette.
  2. Use exactly the size on the card. Only three are used: 1024 × 1024, 1536 × 1024 and 1024 × 1536.
  3. Transparent means real alpha. If an image comes back with a white, grey or checkerboard background where the card says transparent, ask for it again with a transparent background.
  4. Fill the canvas as described. Earlier deliveries came back with the drawing in a thin strip of a larger canvas. That is a fail; make it again.
  5. Pairs must match. For off/on and up/pressed pairs, make the second from the first, at the same size and position, so that switching between them moves only the light or the press.
  6. Save each image as PNG with the exact file name on the card, put them all in one zip, and add a short note listing anything that is not as asked. Tick a card when its part is done; the ticks are remembered in this browser.
