The Beetmachine Collection

The drums: a kick, a snare and the hats and cymbals, every hit synthesised and no samples anywhere, and Beetmachine, the kit that plays all three.

Three drum synthesisers built as a set, each on physical controls rather than a simulation per machine: Kickstart for the kick, Snare Tactics for the snare, Hats Off for the hats and cymbals. Beetmachine puts them together: eight slots, each a real copy of one of the three with its own full panel, played from one MIDI pattern, with chokes, outputs, a BWFX rack and twenty-four themed kits, from STUDIO and 808 to DUB SPACE, DOOM and BLACK METAL. All four wear the same vintage machine controls and type.

Installing

Each folder holds the plug-in, its standalone and its manual. Copy each .vst3 folder — the whole folder, not the file inside it — into C:\Program Files\Common Files\VST3\Brokild\ and rescan in your DAW. Windows will ask for administrator permission, which is normal. The standalones need no installing: run them where they sit.

Patches live in Documents\Brokild patches\<plug-in>, one folder each, and nothing is written anywhere else.
