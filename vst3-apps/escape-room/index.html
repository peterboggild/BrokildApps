Escape Room

A noise machine that will not tell you what its knobs do.

Five coupled noise cells, a playable four-voice resonant filter, three effects, and a six-bit lock that rewires the entire machine into any of sixty-four rooms. Nothing on the panel is labelled with what it does — but every room is fixed, repeatable and learnable, and there is a legend hidden in the door if you can find it.

↓ Download for Windows (zip, 7 MB) Build 260826.4 Manual (PDF, 15 pages)

What it does

It is a synthesiser built as a puzzle. The sound is genuinely good — a wall of coupled noise you can play chords on — but the instrument deliberately refuses to explain itself, and getting good at it means learning it rather than reading it.

Five cells

None of them is an oscillator

A geiger cloud of impulses, two sines modulating each other into chaos, pink noise through three wandering formants, five inharmonic strings, and a crusher that eats the room's own output and feeds it back.

The door

A filter you actually play

Four independent voices of state-variable filter at up to Q 58, tuned by MIDI or by the keys on the panel. Play chords and the noise snaps into harmony. A second resonance can be set anywhere up to two octaves above.

The lock

Sixty-four reproducible rooms

Six lamps, one number. It seeds eight wires — each listening to something in the room and moving something else. Sigil 41 always builds the same eight wires, so a room you liked can be found again.

Three traps

Effects with too few knobs

A slice repeater that reverses and double-speeds at random, a tape-warbled delay whose one knob is feedback and level, and a four-line reverb with an octave-up shimmer that climbs forever.

Modulation you can see

Every knob the loom is pushing grows a dotted ghost arc just outside it, spanning from where you set it to where the room has actually put it. Turn BIND to zero and the whole machine goes inert — every control does exactly what it says, which is how you learn what it says. Turn it up and the room starts moving itself.

Download and install

Two minutes. There is no installer — a VST3 plugin is a folder you copy into place.

  1. Download the zip. Escape-Room-VST3-win64.zip (7 MB). On GitHub you can also press the green Code → Download ZIP button on the repository and find it under vst3-apps/escape-room/.
  2. Unzip it. Right-click → Extract All. Inside you get an Escape Room.vst3 folder, a standalone Escape Room.exe, the manual and a readme.
  3. Copy the plugin folder into the VST3 directory. Move the whole Escape Room.vst3 folder — not just the file inside it — into C:\Program Files\Common Files\VST3\. Windows will ask for administrator permission; that is normal.
  4. Rescan plugins in your DAW. In Ableton Live: Preferences → Plug-Ins → Rescan. It appears as an instrument called Escape Room, by Brokild. Drop it on a MIDI track — it starts making sound immediately, before you play anything.
If the plugin window is blank, install the Microsoft Edge WebView2 runtime. The interface is drawn with WebView2, which ships with current Windows but can be missing on older or heavily stripped installations. The instrument keeps making sound with the window shut either way.

Playing it

The manual has a ten-minute quick start, a full control reference and eight recipes. A few to begin with:

Try this

Playable rust organ

One broadband cell, BIND at zero, resonance at 84 %, key follow at 100 %, and the twin resonance a fifth up. Now play chords. It is the cleanest thing the instrument does, and it comes out of pure noise.

Try this

Bell mine

Seal cell I and open cell IV with a long decay. The strings keep ringing — because cell I strikes them whether or not it is switched on. Nothing on the panel says so.

Try this

The room eats itself

Open GORR and turn its second knob up. It crushes the room's own output and feeds it back through the filter, so playing notes steers the howl. The CLAMP lamp will be lit and that is fine.

Patches are small readable files

ENCODE in the header puts an ordinary Save dialog in front of you, already suggesting the room you are in. DECODE opens the patch folder as a menu, with sub-folders flying out sideways beside the loose patches. A patch is the forty-five numbers and nothing else — plain JSON you can read, diff, back up or mail to someone. They live in a folder called User presets beside the installed plugin, so a library travels with it.

There is a legend

A full plain-English decoding of every mark on the panel, plus this room's eight wires written out in words, generated from whichever sigil you are actually in. It is not on a menu, and this page is not going to tell you where it is either. It is not far.
