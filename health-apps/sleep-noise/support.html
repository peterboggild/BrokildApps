If something is going wrong, these four things make it far easier to work out what: which device you are using, which version of iOS, the version line printed at the very bottom of the app's screen, and what you had set up when it happened — which faders were open, the sleep timer, whether the screen was locked.

The usual questions

I tap play and hear nothing

The first time you use a given sound, the app has to generate it — the sound is not a recording, it is made from scratch on your device. You will see "Preparing…" for a few seconds. Every later start is immediate.

If that is not it: check the phone is not in silent mode or muted at the hardware switch, check the volume fader in the app is not at zero, and check at least one fader in the Mix section is above zero. Every fader down is a legal setting — the timer still runs — so it is possible to have the app happily "playing" silence.

Does it keep playing when the screen locks?

Yes. That is the whole point, and the app is built around it: the sound is played by the phone's own audio engine, not by the on-screen part of the app, so it carries on with the screen off for as long as the sleep timer says.

You will see it on the lock screen, with what is playing and how much time is left, and you can pause and resume from there or from Control Centre.

The sound stopped in the night

Almost always this is the sleep timer doing its job. Check the timer setting — if it says Play for 8 h, it stopped after eight hours. Set it to ∞ in the duration row if you want no limit at all.

The other cause is an interruption: a phone call, an alarm, Siri, or headphones being unplugged. The app pauses for those and deliberately does not start itself again — sound coming back on by itself at three in the morning is worse than sound not coming back. Tap play, or use the lock screen, and it picks up where it left off with the remaining time intact.

I turned the volume up and then it got loud

That was the fade-in, and it is now one second by default for exactly this reason. If you have a longer fade-in set — you can see it under More options → Fade in — set the volume you actually want first, then start it, because the sound is still on its way up while you are judging it.

How do I stop it without unlocking the phone?

From the lock screen or Control Centre, like any other audio. Or set a sleep timer and let it fade out on its own, which is what it is for.

Which sound should I use?

Start with a preset and adjust from there. Deep is plain brown noise, the usual first choice — it masks traffic, snoring and footsteps with no hiss. Rainroom is brown under soft rain, which is where most people end up. Shore is surf.

If it feels harsh over a whole night, pull Tone down: darker is gentler on the ears, brighter masks more speech. If you can hear the individual rain drops too clearly, try soft rain instead — it is the same weather heard through a closed window.

Does it work with no signal?

Completely. The app makes no network connections at all, so aeroplanes, tents and basements are all fine. Try it in airplane mode if you like — it behaves identically.

Is it draining my battery?

Playing sound overnight with the screen off costs relatively little. What costs a lot is keeping the display on, so if you use the blackout screen all night, turn off More options → Keep the screen on in blackout. The sound carries on with the screen off either way.

The ambient synth keeps me awake

It probably will, and that is expected. Anything melodic holds the attention more than plain noise does, so the five synth themes are meant for lying awake on purpose — meditating, reading, resting — rather than for sleeping through. For sleep, set the Ambient synth to Off and use the noise faders alone.

My settings disappeared

Settings live on your device and nowhere else — there is no account and nothing is synced, so deleting the app removes them, and a new phone starts fresh. On iOS the app keeps a second copy in the system's own storage and restores it if the first is ever cleared, so this should be rare.

Is there a subscription?

No. You buy it once. There is no account, no advertising, no analytics and no tracking of any kind — see the privacy policy, which is short because there is not much to say.

Can I use it in a browser instead?

Yes — the web version is the same app and is free. The iOS version exists because a browser cannot be relied on to keep playing all night with the screen locked; that part is native.

Reporting a bug

The most useful bug report says what you expected, what happened instead, and whether it happens every time. If it involves the sound stopping, the two things worth noting are how long it had been playing and whether the screen was locked.

Send it to brokildapps@gmail.com with the four details from the top of this page.
