# Blue steel damage and dirt decals

Seventeen square PNG sprites for overlaying damage and dirt on a cobalt-blue painted steel panel.

- Size: 1024 × 1024 px
- View: straight top-down
- Lighting: soft, from the upper left
- Background: flat `#808080`
- One centered decal element per image

## Damage decals

1. `01-deep-gouge.png` — deep steel-revealing gouge
2. `02-hairline-scratch.png` — fine, barely-through scratch
3. `03-parallel-scuff.png` — three-line localized scuff
4. `04-paint-chip.png` — irregular exposed-steel paint chip
5. `05-shallow-dent.png` — shallow impact dent
6. `06-worn-abrasion.png` — rubbed-through paint wear
7. `07-cracked-paint.png` — localized paint crazing
8. `08-rust-hole-round.png` — round irregular rust break
9. `09-pitted-corrosion.png` — grouped corrosion pits
10. `10-impact-puncture.png` — compact star-shaped impact
11. `11-rust-hole-elongated.png` — elongated rust break
12. `12-rust-hole-angular.png` — angular/crescent rust break
13. `13-rust-hole-twin-lobed.png` — connected twin-lobed rust break
